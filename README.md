# The Blood

**혈액을 소모해 싸우고, 사냥으로 살아남는 뱀파이어 멀티플레이 FPS · PvPvE**

The Blood는 **디벨로켓 언리얼 11기 팀 프로젝트**입니다. Unreal Engine 5.8과 C++을 기반으로, 체력과 공격 자원을 하나의 **혈액**으로 통합한 전투를 개발합니다. 플레이어는 뱀파이어가 되어 다른 플레이어와 싸우고, 인간과 혈액팩으로 자원을 보충하며, 낮과 밤에 따라 달라지는 전장에서 생존합니다.

> 개발 중인 프로젝트입니다. 아래 게임 시스템과 조작은 기획 목표를 포함하며, 구현 및 플레이 테스트 결과에 따라 변경될 수 있습니다.

## 핵심 플레이

### 혈액을 사용하는 전투

혈액은 생존을 위한 체력이자 스킬과 전투 행동에 사용하는 자원입니다. 공격에 투자할 혈액과 생존을 위해 남길 혈액 사이에서 판단해야 합니다.

- 피격과 햇빛 노출로 혈액이 감소합니다.
- 스킬 사용과 총기 운용에 혈액을 소모합니다. 사격마다 소모할지, 재장전 시 일괄 소모할지는 프로토타입에서 비교합니다.
- 공격 명중 시 클래스별 흡혈 규칙에 따라 혈액을 회복합니다.
- 인간 사냥과 혈액팩 획득으로 전투에 필요한 혈액을 보충합니다.

### 낮과 밤에 따라 달라지는 전장

낮에는 햇빛을 피해 실내와 그림자를 활용하고, 밤에는 자원과 몬스터를 둘러싼 경쟁에 참여합니다.

| 시간대 | 환경 규칙 | 주요 출현 요소 |
| --- | --- | --- |
| 낮 | 직사광선에 노출되면 혈액 감소 | 인간 |
| 밤 | 햇빛 피해 비활성화 | 인간, 혈액팩, 몬스터 |

### 최후의 저항, 광폭화

사망 판정 시 **목숨당 한 번** 광폭화에 진입하는 시스템을 계획합니다. 광폭화 중에는 총기 대신 공통 근접 공격을 사용하며, 무적 상태에서 생존 기회를 노립니다. 지속 시간, 일반 상태 복귀 조건, 최종 사망 규칙은 플레이 테스트를 통해 결정합니다.

### 클래스와 PvPvE

| 구분 | 전투 콘셉트 |
| --- | --- |
| 급진파 뱀파이어 | 현대식 총기를 사용하는 원거리 전투 |
| 보수파 뱀파이어 | 근접 공격과 혈액을 활용한 특수 기술 |

플레이어 간 전투에 더해, 도주하는 인간을 사냥하거나 플레이어를 추적하는 몬스터를 상대합니다. 몬스터 처치 보상으로 혈액 회복, 흡혈 강화, 혈액 소모량 감소, 햇빛 피해 완화, 무기 강화 등을 검토합니다.

## 기술 구성

| 기술 | 활용 |
| --- | --- |
| Unreal Engine 5.8 · C++ · Blueprint | 게임 로직 및 에디터 기반 콘텐츠 구성 |
| Gameplay Ability System (GAS) | 능력·효과·전투 상태를 확장할 기반 |
| GameplayTags | 상태와 기능을 구분하는 태그 체계 |
| Enhanced Input · CharacterMovement | 이동·시점·점프·앉기 입력과 로코모션 |
| UMG | HUD 및 게임 UI |
| PCG | 맵 배치 및 동적 생성 관련 작업 |
| Git · GitHub | 코드·설정·문서 버전 관리 |
| Unity Version Control | Content 에셋 버전 관리 |
| Notion | 기획, 회의록, 업무 및 로드맵 관리 |

현재 소스는 공통 캐릭터 `ATBCharacterBase`를 플레이어 `ATBPlayer`와 몬스터 `ATBMonster`가 상속하는 구조입니다. 플레이어 ASC는 `ATBPlayerState`에 두고, 기본 로코모션은 Enhanced Input과 CharacterMovement로 처리합니다. 플레이어에는 1인칭 팔 메시와 다른 플레이어에게 보이는 전신 메시를 분리해 구성합니다.

프로젝트 클래스와 관련 코드에는 **`TB` 접두어**를 사용합니다.

## 기본 조작 계획

| 동작 | 입력 |
| --- | --- |
| 이동 | `W` `A` `S` `D` |
| 시점 조작 | 마우스 이동 |
| 기본 공격 / 조준 | 마우스 좌클릭 / 우클릭 |
| 점프 | `Space` |
| 달리기 / 앉기 | `Shift` / `Ctrl` |
| 재장전 | `R` |
| 스킬 1 / 스킬 2 | `Q` / `E` |

실제 사용 가능한 입력은 현재 개발 브랜치와 Input Mapping Context 설정에 따라 달라집니다. 걷기와 좌우 기울이기는 도입 여부 및 키 배정을 검토 중입니다.

## 프로젝트 실행 준비

1. Unreal Engine **5.8**과 해당 엔진의 C++ 빌드에 필요한 개발 도구를 준비합니다. 코드 편집에는 Rider 또는 Visual Studio를 사용할 수 있습니다.
2. 이 저장소를 클론합니다.
3. 팀의 **Unity Version Control**에서 같은 작업 버전에 맞는 `Content` 에셋을 동기화합니다. 접속 정보와 워크스페이스 구성은 팀 내 안내를 따릅니다.
4. `Develrocket_TeamProj.uproject`에 활성화된 플러그인을 준비합니다. 엔진 플러그인 외에 `ModelContextProtocol`, `EditorToolset` 등 에디터 도구의 설치 여부도 확인합니다.
5. 프로젝트 파일을 생성하거나 IDE에서 `.uproject`를 열고, `Develrocket_TeamProjEditor`를 `Development Editor / Win64` 구성으로 빌드합니다.
6. Unreal Editor에서 팀이 공유하는 테스트 맵을 열어 실행합니다. 멀티플레이 검증 시 플레이어 수와 리슨 서버 실행 옵션을 설정합니다.

> **Git 클론만으로 전체 에셋이 제공되지는 않습니다.** 현재 `.gitignore`에서 `Content/`를 제외하고 있으며, 에셋은 Unity Version Control로 별도 관리합니다. `Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`와 IDE 생성 파일도 Git 관리 대상에서 제외합니다.
