# Windows 모니터 화면 끄기

현재 연결된 모든 모니터를 한 번에 디스플레이 절전 상태로 보낸다. 물리적인 전원을 차단하지 않는다. 시스템 Sleep·Hibernate·Shutdown, 잠금·로그오프, 프로그램 종료, 작업 저장·커밋은 수행하지 않는다.

## 대상과 실행 조건

- Windows의 실제 사용자 데스크톱 세션에서 실행한다. Codex가 Linux·WSL·컨테이너·서비스 세션에서 실행된다면 그 세션의 화면 제어를 실제 Windows 디스플레이 제어로 간주하지 않는다. 사용자 데스크톱에 연결된 Windows 실행 도구가 있는지 확인한다.
- 원격 컴퓨터라면 컴퓨터와 사용자 세션을 확인한다. RDP의 가상 디스플레이와 콘솔의 물리 모니터는 다를 수 있다. 콘솔 모니터 제어가 필요하면 해당 콘솔 세션에서 실행해야 한다. 대상이 불명확할 때만 확인을 요청한다.
- 실행 전 사용자에게 화면을 끄며 작업은 계속 실행된다고 짧게 알린다. 명확한 화면 꺼짐 요청에는 추가 승인을 요구하지 않는다.
- 아래 번들 PowerShell 스크립트를 사용한다. 외부 프로그램, 관리자 권한, 전원 정책 변경은 기본적으로 필요하지 않는다.

## 실행

저장소 루트에서 설치된 PowerShell 7(`pwsh.exe`)로 실행한다. 실제 경로는 현재 체크아웃에 맞게 지정한다. 이미 PowerShell 7에서 실행 중이면 `& ".agents\skills\turn-off-monitors\scripts\turn-off-monitors.ps1"`로 직접 호출해도 된다. Windows PowerShell 5.1(`powershell.exe`)은 실행 정책이 별도로 적용되므로 고정 호출하지 않는다. `pwsh.exe`가 PATH에 없으면 현재 실행 중인 PowerShell 7의 `$PSHOME\pwsh.exe` 경로를 사용한다.

```powershell
pwsh.exe -NoProfile -NonInteractive -File ".agents\skills\turn-off-monitors\scripts\turn-off-monitors.ps1"
```

- Codex Windows 샌드박스에서는 명령이 실제 바탕화면과 다른 `CodexSandboxDesktop`에서 실행될 수 있다. 같은 세션 ID이거나 `UserInteractive=True`인 것만으로 실제 바탕화면이라고 판단하지 않는다. 이 환경에서는 `exec_command`의 `sandbox_permissions="require_escalated"`로 아래 스크립트의 사용자 데스크톱 실행을 요청하고 도구의 승인 결과를 따른다. 스크립트는 `WinSta0\Default`인지 확인하고 다른 데스크톱에서는 메시지를 보내기 전에 오류로 종료한다. 데스크톱 전환이나 보안 설정 변경으로 우회하지 않는다.
- 실행 정책을 우회하지 않는다. 조직 정책으로 스크립트 실행이 차단되면 정책을 바꾸지 말고 차단 원인을 보고한다.
- 스크립트는 `user32.dll`의 `SendMessageTimeoutW`로 `HWND_BROADCAST`에 `WM_SYSCOMMAND / SC_MONITORPOWER` 메시지와 `lParam=2`를 전송한다. 개별 모니터 식별 없이 Windows에 전체 디스플레이 화면 꺼짐을 요청한다.
- 이는 유휴 시간에 따른 화면 꺼짐을 기다리는 방식이 아니다. Codex의 시스템 절전 방지 기능은 변경하거나 해제하지 않는다. 일반적인 시스템 절전 방지 요청과 별개로 화면 꺼짐을 직접 요청한다. 화면 활성화를 반복 요청하는 다른 프로그램이나 입력 이벤트가 있으면 다시 켜질 수 있으므로 절전 방지 설정과 무관한 절대적인 성공을 약속하지 않는다.
- 타임아웃이 있는 한 번의 메시지 전송 후 PowerShell이 종료된다. `HWND_BROADCAST` 타임아웃은 대상 창마다 적용될 수 있어 전체 호출 시간이 지정한 1초보다 길어질 수 있다. 상시 실행 루프, 백그라운드 작업, 입력 차단, 주기적인 재전송을 만들지 않는다.
- 키보드·마우스 등으로 Windows가 디스플레이를 다시 켜는 동작은 그대로 유지한다. 직후 사용자 입력이나 원격 제어 프로그램 때문에 화면이 켜져도 자동으로 다시 끄지 않는다.

## 확인과 제한

- 종료 코드와 출력으로 API 요청 성공 여부를 확인한다. 요청 성공만으로 모든 물리 모니터의 실제 상태를 확인했다고 표현하지 않는다. 드라이버·모니터·사용자 세션에 따른 실제 동작은 Windows에서 관찰해야 한다.
- `SetSuspendState`, `shutdown.exe`, 시스템 전원 변경, 프로세스 종료를 호출하지 않는다. 이 스크립트 자체는 컴퓨터 절전·최대 절전·종료를 요청하지 않으며 실행 중인 작업을 중단하지 않는다.
- 기존 Windows의 자동 시스템 절전 정책은 바꾸지 않는다. 장시간 계속 실행하려면 기존 Codex 시스템 절전 방지 기능 또는 사용자의 전원 정책이 별도로 유지되어야 한다. 이 일회성 스크립트가 시스템 절전을 계속 방지한다고 설명하지 않는다.
- 완료 시 화면 꺼짐 요청 결과와 작업 유지 의도를 짧게 보고한다. Windows에서 실행하지 않았다면 실제 디스플레이 상태나 Codex 절전 방지와의 호환성을 검증했다고 쓰지 않는다.
