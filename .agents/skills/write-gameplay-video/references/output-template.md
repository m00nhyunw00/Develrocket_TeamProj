# 촬영 시나리오 양식

필요한 항목만 사용한다. 표가 허용되는 문서에서는 장면들을 표로 바꿔도 되지만 긴 조작 설명을 좁은 셀에 넣지 않는다. 채팅에서는 번호 목록을 기본으로 한다.

## 1. 영상 개요

- 목적 / 시청자:
- 대상 기능:
- 기준 코드: 저장소·브랜치·커밋 또는 제공 파일. 로컬 변경 포함 여부.
- 기준 문서: 읽은 Notion 문서·절 또는 제공 자료.
- 목표 길이 / 제안 길이: 지정 여부와 예상임을 구분.
- 촬영 전제: 빌드·맵·참여 인원·준비 상태 중 확인된 항목만.

## 2. 촬영 순서

### 장면 01. [시청자가 이해할 한 가지 결과]

- 예상 구간 / 길이: 00:00–00:08 / 8초. 실제 녹화 타이밍이 아니면 예상으로 표시.
- 화면: 무엇을 어느 시점·구도로 보여줄지.
- 준비: 시작 상태와 필요한 데이터·설정. 모르는 값은 확인 항목으로 남길 것.
- 조작: 촬영자가 순서대로 수행할 행동.
- 확인할 결과 / 컷 종료: 화면에서 어떤 변화를 확인하고 마칠지.
- 자막: 그대로 붙일 문장. 미검증이면 '촬영 확인 후 사용'으로 구분.
- 근거 상태: 문서상 계획 / 코드 확인 / 화면 확인 / 자료 충돌 중 해당 상태.
- 근거: 읽은 문서 절, 실제 파일·함수·커밋 등.
- 선택: 전환, 재촬영 조건, 대체 장면, 내레이션. 필요한 경우에만.

장면 길이를 더하여 전체 길이를 확인한다. 도입·전환·마무리도 계산에 넣고 아직 촬영되지 않은 부분의 시간은 가편집 제안으로 유지한다.

## 3. 복사용 자막

장면 번호와 확정 가능한 문장을 분리하여 제공한다. 코드만 확인한 기능은 별도의 '촬영 확인 후 사용할 자막 후보' 목록에 둔다. '키를 누른다', '카메라를 이동한다' 같은 촬영 지시를 시청자 자막에 섞지 않는다.

## 4. 촬영 전에 확인할 것

- 아직 확인하지 못한 입력·에셋·화면 동작.
- 문서와 코드의 차이 및 촬영할 버전에 관한 확인.
- 빌드·실행·멀티플레이 검증의 수행 여부.
- 장면에서 가리거나 제외할 개인 정보·비공개 정보.
