# 프로젝트 스킬 목록 조회

현재 존재하는 스킬을 실제 파일에서 확인하고 한국어로 간결하게 정리한다.

## 조회 범위

- 별도 범위가 없으면 현재 프로젝트 루트의 `.agents/skills` 전체를 조회한다. `.agent`나 과거 대화의 목록을 대신 사용하지 않는다.
- 사용자가 다른 경로나 특정 스킬들을 지정하면 그 범위만 조회한다.
- 전역 스킬이나 플러그인을 포함한 전체 목록을 명시적으로 요청하면 현재 세션의 스킬 카탈로그와 접근 가능한 설치 경로를 함께 확인한다. 프로젝트 목록과 출처를 구분하고 프로젝트 전용 조회였던 것처럼 표현하지 않는다.
- 경로를 찾지 못하면 현재 세션 카탈로그만으로 프로젝트 설치 목록을 단정하지 않는다. 확인 가능한 범위와 누락을 밝힌다.
- 숨겨진 디렉터리 검색을 포함해 스킬 파일을 확인한다. 리소스 디렉터리를 별도 스킬로 세지 않는다.

## 정보 읽기

1. 각 `SKILL.md`의 frontmatter와 필요한 본문을 읽어 실제 기능을 확인한다. 목록에 있다는 이유만으로 대상 스킬을 실행하지 않는다.
2. **스킬 본명:** frontmatter의 `name` 값을 그대로 사용한다. 디렉터리 이름과 다르면 이를 숨기지 않는다.
3. **한국어 표시 이름:** `agents/openai.yaml`의 `interface.display_name` 값을 그대로 사용한다. 표시 파일이나 필드가 없으면 `미설정`, 영어로 설정되어 있으면 실제 이름과 함께 `한국어 미설정`이라고 표시한다. 번역해서 실제 설정인 것처럼 제시하지 않는다.
4. **스킬 설명:** frontmatter의 `description`과 본문을 바탕으로 주요 기능과 중요한 적용 범위를 한국어 한 문장으로 요약한다. 파괴적 동작이나 외부 전송 기능이 있으면 기능 설명에서 생략하지 않는다.
5. 읽을 수 없거나 형식이 잘못된 파일은 제외해 숨기지 말고 해당 스킬의 확인 불가 항목과 이유를 표시한다.

## 응답 형식

조회 범위와 개수를 먼저 밝히고, 본명 기준으로 정렬해 모든 스킬을 다음 표에 담는다.

| 스킬 본명 | 한국어 표시 이름 | 스킬 설명 |
|---|---|---|
| `inline-function-args` | 함수 인자 한 줄 정리 | 제공 코드, 지정 파일 또는 Rider 열린 파일의 함수 호출 인자를 한 줄로 정리 |

표의 예시는 형식 참고용이며 실제 결과는 매번 조회한 값으로 작성한다. 스킬이 많아도 임의로 일부만 추리지 않는다. 여러 출처를 조회했다면 출처별로 표를 나눈다.

이 스킬은 읽기 전용이다. 표시 정보가 누락돼 있어도 자동으로 수정하거나 설치·삭제·커밋하지 않는다. 보완이 필요하면 누락 사실을 알리고 `normalize-skill-format`으로 처리할 수 있음을 안내한다.
